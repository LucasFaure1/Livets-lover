# Assets som må lokaliseres før lansering

Disse filene bruker riktig komposisjon og størrelse, men inneholder fortsatt slovakisk tekst i selve bildepikslene. De er bevisst beholdt som visuelle plassholdere slik at layout og responsive proporsjoner kan kvalitetssikres uten å fabrikkere nye bokutgaver.
